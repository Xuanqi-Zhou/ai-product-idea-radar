## 四、Idea

### 语言 AI 陪练
- **需求**：学习者苦于口语流利度不足，需要能指出具体音节/发音问题的实时纠错陪练，而不是只给整体分数的跟读工具。
- **现状**：讨论集中在用开源工具（如 Enjoy App）做逐句跟读评分和音节级纠错，也有人用 Agent 技能（如 ielts-buddy）把口语陪练融入学习计划，共享做法是自选视频/文本转成可练习的分段材料。
- **方向跟踪**：值得跟踪的方向是让口语陪练支持任意外语视频/文本自动生成带逐句评测和发音定位的练习，并将这类陪练嵌入本地 Agent 工作流。
- **来源**：https://www.zhihu.com/question/641065475/answer/3415615067、https://zhuanlan.zhihu.com/p/2003831453235036734

### 法律 AI 工作流
- **需求**：律师审一份合同前必须弄清交易模式、背景，客户却以为“甩个文件半小时就能确认”，导致一次审查往往要数天反复沟通。
- **现状**：普通人习惯直接用网上的模板合同，律师靠微信反复向客户确认背景信息，已有 LexAI 等 LLM 工具把合同审查、起草、对比打包成智能体，但仍未解决背景采集问题。
- **方向跟踪**：值得跟踪的是让 AI 在审查前主动向用户提问交易结构与商业意图、形成带背景假设的风险清单，而非只对文本做静态审查。
- **来源**：https://zhuanlan.zhihu.com/p/702780746、https://www.zhihu.com/question/530439453/answer/2471635526

### 供应链分析 Agent
- **需求**：供应链运营人员补货分析耗时太长，需要能根据历史数据和关键信息自动给出补货建议的智能助手。
- **现状**：当前做法多是在 GitHub 等开源社区搭建多场景通用决策 Agent（如 DecisionAgent），用信息提取+历史匹配来覆盖供应链等领域，但尚无针对补货分析的专用解决方案。
- **方向跟踪**：值得跟踪决策 Agent 在供应链补货场景的纵向深化，将历史补货数据、库存阈值和异常波动纳入同一套决策链路，输出可复核的补货清单。
- **来源**：https://www.xiaohongshu.com/search_result/69b7d8c2000000001e00d593?xsec_token=AB-g1D-ykyFiBlE_eaNr2ggfPgiZqDwsHBL-jfBc2L_Os=&xsec_source=、https://www.xiaohongshu.com/search_result/6a004139000000003502d069?xsec_token=ABP0K0Er0wHpdCE7jLE3TqeQ33ExrJoPpWqLtXr-T3_NE=&xsec_source=
