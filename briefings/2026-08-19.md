## 四、Idea

### 法律 AI 工作流
- **需求**：律师需要 AI 工具分担合同审查中条款审核这项耗时任务。
- **现状**：用户仍在求推荐现成的合同审查 AI，开源社区已有项目尝试用 LLM 集成合同审查、文书生成和法律检索。
- **方向跟踪**：把合同审查与法规、案例检索集成到同一个 LLM Agent 流程中，让审查结论能直接追溯到具体法条或判例。

### 智能旅行助手
- **需求**：自由行用户需要把小红书等渠道的上百条碎片化攻略整理成可执行的路线。
- **现状**：当前主要靠人工在社交平台收集和拼凑信息，部分开源方案已尝试用 Agent 完成规划、社交平台调研和交互式地图生成。
- **方向跟踪**：值得继续跟踪的方向是自动抽取社交平台笔记中的地点、时间与建议，生成可编辑的行程地图或结构化行程单。

### 供应链分析 Agent
- **需求**：供应链运营人员需要从耗时的手工补货分析中解脱出来，更快完成补货判断。
- **现状**：当前讨论集中在梳理供应链关键指标和职业出路，已有 GitHub 项目将供应链优化作为多场景决策 Agent 的其中一个场景，但未见针对补货分析的专门流程或工具。
- **方向跟踪**：值得继续跟踪的方向是，把供应链关键指标识别和历史数据匹配能力收窄到补货分析任务，直接输出可执行的补货建议。
