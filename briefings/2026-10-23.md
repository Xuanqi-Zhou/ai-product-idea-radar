## 一、开发工具推荐

### Leonxlnx/taste-skill
- **核心亮点**：给编码 Agent 补上审美判断
- **亮点关键词**：艺术方向、参考图约束、浏览器截图自检、去除 AI 味
- **复用方向**：把“先定艺术方向、再提供参考图、最后由浏览器截图自检”这套约束流程，迁移到文案、PPT 等其他生成式产物的质量把控上。
- **最小 MVP**：第一版只做一个 skill：让 Agent 写页面前先选定一种艺术方向并附上两张参考图，写完后用无头浏览器截图对照参考图，不合格就重写。
- **标签**：开发者工具、浏览器自动化、图像/设计生成
- 来源：GitHub｜[查看原文](https://github.com/Leonxlnx/taste-skill)

### sandbox-quantum/switch
- **核心亮点**：把 agent 变成群里的同事，@ 一下就接活
- **亮点关键词**：群内 AI 同事、自托管部署、任意模型接入、五个 IM 打通
- **复用方向**：把 agent 以成员身份放进 Slack、Teams 这类现有聊天频道，让用户在对话里直接派活并旁观执行过程，而不是再开一个独立的 AI 界面。
- **最小 MVP**：先只接 Slack 一个端，让一个 agent 作为频道成员，被 @ 时接任务并把执行结果回帖到同一线程。
- **标签**：工作流自动化、多 Agent 协作
- 来源：GitHub｜[查看原文](https://github.com/sandbox-quantum/switch)

### shim-cli
- **热度**：🔥PH 197票｜28评
- **核心亮点**：看清编码助手发出的请求并脱敏
- **亮点关键词**：本地代理拦截、敏感信息脱敏、请求成本追踪
- **复用方向**：把本地代理放在编码助手与模型 API 之间，转发前先按规则脱敏密钥令牌并记录每次请求与花费；这套拦截层可以迁移到任何会把代码发往外部模型的开发工具。
- **最小 MVP**：第一版先起一个本地代理接管编码助手的 API 出口，逐条展示请求内容与成本，命中规则的密钥或令牌替换后再转发。
- **标签**：开发者工具
- 来源：Product Hunt｜[查看原文](https://www.producthunt.com/products/shim-cli?utm_campaign=producthunt-api&utm_medium=api-v2&utm_source=Application%3A+ai-idea-radar-v4-2+%28ID%3A+294543%29)

## 四、Idea

### 语言 AI 陪练
- **需求**：口语学习者需要开口练习时能精确知道自己哪个音节读错，而不是只拿到笼统的好坏评价。
- **现状**：目前主要依赖开源工具 Enjoy 的跟读与纠音方案，对上传视频自动生成字幕分段并指出具体发音错误音节。
- **方向跟踪**：基于用户自选的真实语料（美剧、视频）自动生成逐句评分与音节级纠音反馈的口语练习内容。
- **来源**：https://www.zhihu.com/question/641065475/answer/3415615067、https://zhuanlan.zhihu.com/p/2003831453235036734

### AI 面试官
- **需求**：求职者准备面试讲稿时，难以预判面试官会围绕成果归属、个人贡献和决策细节连环追问，模拟面试耗时且缺少针对性反馈。
- **现状**：大家主要靠刷 LeetCode、做 take-home project，或用 GitHub 项目素材生成定制简历与面试讲稿、整理可被追问的知识体系来应对，讨论集中在算法面试与实际工作脱节、评估难标准化。
- **方向跟踪**：值得继续跟踪的是围绕个人项目素材自动生成“追问链”、逐轮检验回答一致性的模拟面试产品，重点在追问贡献归属、决策过程和踩坑细节并给出针对性反馈。
- **来源**：https://zhuanlan.zhihu.com/p/1991086840866951352、https://www.zhihu.com/question/1994417989173389039/answer/2001647806235050790

### AI 宠物陪伴
- **需求**：独居者在生病或阴雨天长期闭门不出时，需要有人持续搭话并确认身体状况，而非靠刷手机、看电视或摆弄花草打发时间。
- **现状**：目前主要靠自我消磨、和家人零散聊天来应对，产品侧则用带认知记忆、多 Agent 协作的 AI 情感陪伴助手维持连续对话。
- **方向跟踪**：值得跟踪的产品化方向是让 AI 陪伴从被动等用户开口，转向在识别到长时间沉默或不适表述后主动追问，并把异常状态同步给子女或照护者。
- **来源**：https://zhuanlan.zhihu.com/p/2051965792061764588、https://www.zhihu.com/question/2053800644537012873/answer/2086052496443756864
