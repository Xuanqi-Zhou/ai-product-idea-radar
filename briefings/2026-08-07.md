## 四、Idea

### 法律 AI 工作流
- **需求**：律师与法务希望将消耗大量时间的标准合同起草、审查和比对工作交给AI，以便自己专注于高附加值的法律策略与谈判。
- **现状**：从业者正尝试使用Ironclad、幂律智能等现有AI合同工具进行自动化审查与全生命周期管理，同时围绕“AI能否真正替代人工审阅”在评论区激烈争论。
- **方向跟踪**：重点跟踪方向是利用公开法律条文与判例训练领域模型，从单纯的条款审查向前延伸至结合案例检索的合同起草、比对和纠纷风险预判。

### 语言 AI 陪练
- **需求**：外企职场人士在口语对话中迫切需要实时纠音和地道表达反馈，以克服从阅读英语到流利口语的思维切换障碍。
- **现状**：当前用户主要靠预约外教一对一练习，并辅以精听和播客输入，讨论集中在如何找到能及时纠正细节的真人陪练，同时 GitHub 上已出现集成口语陪练的本地 AI Agent 技能包。
- **方向跟踪**：从外教纠音和表达教学的核心体验出发，探索用可本地部署的大模型 agent 实现低延迟、可随时中断并给出替换表达和发音动作提示的交互式口语陪练。

### 供应链分析 Agent
- **需求**：商家急需动态响应需求变化、自动生成补货计划以避免爆单或库存积压。
- **现状**：当前主要由人工反复调整销量预测和补货方案，过程耗时且易出错。
- **方向跟踪**：面向跨境卖家打造可依据实时需求变动自动协调多仓补货与库存分配的智能决策代理。
